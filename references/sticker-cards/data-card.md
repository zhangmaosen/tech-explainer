# data-card — 参数卡

## 语义
把"谈资级硬核点"装进一张游戏/杂志式参数卡：标签小字 + 数值大字，逐行亮相。
观众看到"卡片"就知道要报参数了，是硬核密度的视觉承诺。对决场景的角色卡
（fighter-card）是它的特化（见 stages/theater.md versus 皮肤）。

## 参数
- 卡片宽 560–720px（横屏栏内），4–6 行；每行 = 标签（≥44px 次要色）+ 值（≥64px 主色）。
- 行 stagger 入场（每行 6–8f 间隔），值可配 number-roll。
- 状态/评价用词带色标：领先=绿、追赶=橙、落后/风险=红；一张卡至多一个色标焦点。
- 边框 2px 半透明 + 角部细节即可，**发光克制**（V2/Q4：光效不群发）。
- 标题行可选：实体名 ≥80px。

## 已知坑
- 行数 >6 = 文档不是视频（读不完，砍行或拆两卡）。
- 标签和值无层级（一样大=平）。
- 每行都给色标 = 没有焦点。
- 卡在屏中孤悬：卡片要和口播指涉的对象贴纸同框（左图右卡）。
