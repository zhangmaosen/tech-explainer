# number-roll — 数字滚动

## 语义
数字（推力/成本/百分比/年份）从 0 或起点快速滚动到目标值，在口播读到该数字的
那一帧开始/命中。财经与硬核参数视频的强相关手法。

## 参数
- 滚动：easeOutExpo，20-32f，越接近目标越慢（减速停）。
- 起点默认 0；同类连续多个数字可阶梯出现。
- 单位（吨/%/bar/亿）跟随数字，字号略小。
- 命中目标值时轻微弹一下（scale 1.0→1.12→1.0）+ 可配色（涨绿跌红或情绪色）。
- 字号 ≥140px，主角地位。

## 钉帧（关键）
timeline.json 的 pins 给出该数字关键词的 frame，滚动**结束**（命中）落在或略后于
该帧，让"听到数字"和"看到数字定格"同步。

## 已知坑
- 匀速滚动（该减速停）。
- 没钉帧，数字和口播错位（A2 失败）。
- 一堆数字同时滚，观众抓不住重点。
