# versus-diagram — 双图对比讲解

## 语义
"为什么 A 和 B 不一样？"的标配版式：左右各一张图，正上方/正中一个大字提问，
差异处用 marker-highlight 圈出。比单图讲解多一层"对照"，是机制解释段里
"对比型知识点"的主力。

## 参数
- 双图各宽 560–720px，分居左右栏（x≈180 / x≈1020），同 y 对齐（y≈220–320）。
- 居中提问标题 ≥96px，压在双图上方正中（y≈140–220）；问句形式（"为什么是全流量？"）。
- 双图之间可放 VS 小徽章或双向箭头，但不要抢标题。
- 差异处：marker-highlight 圈 + 一句话注（≥48px），随口播逐侧点亮。
- **双图必须同源**：同一套风格词、同一批生成（comfyui-assets 的 diagram 流程，
  禁 rembg）；风格漂移 = 廉价（P2 类）。

## 已知坑
- 双图各自精彩但没有"对照点"：必须有一个明确差异维度，且被圈出来。
- 标题太小或太靠上出安全区。
- 双图 + 标题 + 注解 + 字幕同时挤：内容下沿 900 是硬线，注解放图内或图下。
- 竖屏不要用此卡（只能上下堆，对照感全失）——竖屏用单图 flow-diagram 替代。
