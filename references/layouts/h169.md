# layouts/h169 — 横屏 16:9 (1920×1080) 版式总则

默认主力画布。竖屏版式见附录（本文件末节）；3:4 折中预设参数见 helpers CANVAS.v34。
所有坐标/字号与 `components/helpers/index.ts` 的 `CANVAS.h169` 一致，组件从 timeline
的 `canvas` 字段解析，**不要在组件里写死坐标**。

## 分区图

```
y=0    ┌────────────────────────────────────────┐
       │ 顶部带 (0–140): 横幅/栏目标签/对决称号    │
y=140  ├────────────────────────────────────────┤
       │                                        │
       │   内容安全区 (140–900, x 120–1800)      │
       │   核心贴纸/卡片/图表/角色               │
       │                                        │
y=900  ├────────────────────────────────────────┤
       │ 字幕带 (940–1010, x 120–1800)          │
y=1080 └────────────────────────────────────────┘
```

- **marginX 120**：内容/字幕左右边距。平台 UI（视频号横屏进度条、B站播放器控件）
  压底约 60px，字幕带下沿留足。
- **横屏的第一原则：左右分栏，而不是上下堆叠**。竖屏的"上图下文"到了横屏一律
  优先考虑"左图右卡 / 左A右B"。

## 与竖屏的版式映射（8 张既有卡）

| 配方卡 | 竖屏 (v916) | 横屏 (h169) |
|---|---|---|
| title-pop | 屏中大字，y≈760，≥180px | 屏中大字，y≈400，140–200px；钩子句可左对齐放左栏 |
| number-roll | 屏中，y≈820，180px | 居中或左栏，y≈420，150–180px；对比数字时左右各一 |
| list-flyin | 整宽逐条堆叠 | 单栏列表（x≈200–1100）或双栏分两组，逐条飞入不变 |
| compare-bar | 双条竖向排列 | 双条横排并排（左A右B），条形仍可横向生长 |
| emoji-pop | 点缀位置随意 | 同，注意别落到字幕带 |
| marker-highlight | 圈大字/贴纸 | 同 |
| flow-diagram | 整宽居中 | 流程横向展开（左→右）优先，更贴合宽屏 |
| sticker-image | 居中，宽 460–700 | 左/右栏主视觉，宽 520–800，另一侧配文字卡 |

## 新横屏原生卡

- **data-card**（参数卡）：见 `sticker-cards/data-card.md`。横屏右栏/左栏常客。
- **versus-diagram**（双图对比）：见 `sticker-cards/versus-diagram.md`。横屏原生，
  竖屏只能上下堆（不推荐）。

## 字幕（横屏档）

- 字号 72px、描边 4–6px，与竖屏同绝对值（手机全宽播放时物理大小相当）。
- chunking ≤13 字/组的规则不变（这是节奏规则不是宽度规则）；一行 936px 左右，
  居中落在 1680 容器内，两侧留白自然。
- 字幕带 y=940，**内容下沿 900 是硬线**，贴纸不得侵入。

## 附录：竖屏 v916 (1080×1920) 存档参数

- 安全区：内容 y 420–1280；字幕容器 x=30, w=1020, y=1420，72px。
- 版式：上图下文、逐条堆叠；核心元素居中。
- 适用：视频号短平快信息流爆款。选画布见 pipeline.md 阶段 0。
