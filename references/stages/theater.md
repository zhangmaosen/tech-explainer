# stages/theater — 舞台剧类舞台设计规范

**隐喻**：固定机位的单目舞台，角色贴纸在台上进出，聚光灯切换。
**适用叙事**：冲突、博弈、对决、拟人化叙事（把两方力量/概念拟人成角色对台）。
**难度**：★★★★（角色调度 + 进出场时机对齐台词）。

## 架构：通用底盘 + 可插拔皮肤

- **底盘**（`components/stage/TheaterStage.tsx`）：多层布景 + 角色调度，与皮肤无关。
  层序：幕布背景 → 舞台地板 → 聚光灯/光池 → 角色贴纸 → 道具层（本句贴纸）→
  皮肤装饰层 → 字幕层。
- **皮肤**：只提供装饰层 ReactNode（横幅/徽章等 chrome），不动底盘。
  第一套皮肤 = `versus`（见 `skins/versus.md`）。storyboard 写法：
  `stage: "theater", skin: "versus"`。
- **配方卡**：皮肤附属卡（fighter-card / evolution-chain）按层贴纸走 layers，
  不进底盘。

## 空间模型（h169 横屏，1920×1080）

- 舞台地板线 y≈0.86H（930），角色脚站线上；幕布两侧暗角。
- 站位：左 x≈0.24W / 中 0.5W / 右 0.76W。通常 2 个角色，至多 3 个。
- 角色宽 ≈ 0.42H（~450px）；顶部带（0–140）留给皮肤横幅。
- 字幕带与 Slide 相同（y 940–1010），角色与道具不得侵入内容下沿 900。

## 角色调度（核心难点）

- **进出场对齐台词**：角色在被口播提到的那一句进场（滑入 14f），退场同理；
  进出场帧从相邻句边界预算划出，别硬切。
- **聚光灯**：当前被讨论的角色 `lit=true`（脚下有光池），其余压暗
  （brightness 0.5 / saturate 0.5）——聚焦观众注意力。
- **情绪用动画不用新图**：吃瘪/惨败 = `dimmed`（brightness 0.35）+ `rotate` 倾斜；
  高光 = 常态 + 光池。角色跨镜头只有 2 个姿态图（常态/高光），见 character-design.md。
- **角色一致性**：同一角色跨镜头同一形象（comfyui-assets 参考图锁定）。

## 与时间轴对接

- 句边界 = 舞台状态切换点。pins 的关键词帧触发角色动作/道具爆出/皮肤徽章。
- 字幕由 KaraokeCaption 吃 words，与其他舞台一致。

## v1 范围（里程碑2 定稿）

- 做：底盘调度 + versus 皮肤 + 角色 2 姿态 + pins 触发 + 最小 SFX。
- 不做：对话气泡（与字幕冗余，真需要"角色互呛"时再加）；角色配音（旁白不变）；
  BGM；多角色乱斗（>2 同框慎用）。

## 常见坑

- 角色进出场时机和台词错位。
- 多角色全部打亮（没有聚焦）。
- 角色跨镜头形象漂移。
- 全片对决框架不换气（P2：Theater 按镜头选用，机制解释段回 Slide）。
