# character-design — 拟人角色设计规范（Theater 用）

把抽象实体（技术/产品/公司/国家路线）拟人成舞台角色的方法。

## 角色从哪来

1. 从爆点拆冲突：这篇文章的核心张力是哪两方？（规则 H2 的爆点必须能落成
   "谁 vs 谁"，否则这篇文章不适合 Theater，回 Slide。）
2. 每方提炼一个**角色原型**：拳王/挑战者/老匠/刺客/守门人……原型决定外形、
   配色、气质。**规避真实人物肖像**（不生成马斯克/任何真人脸），用原创角色。
3. 每方再提炼 ≤4 行参数（fighter-card 行项）：称号 / 战绩（已知成就）/
   必杀技（核心优势知识点）/ 弱点（可选）。这些就是口播要讲的硬核点。

## 图像生成（Qwen，edit_ref 锁一致性）

- **基准图**：full-body 角色贴纸，风格词与全片贴纸统一（flat vector sticker,
  thick outline, 透明底）。走 default 工作流 + rembg。
- **姿态只有 2 个**：常态（idle）+ 高光（胜利/进攻）。高光图走 edit_ref 工作流，
  以基准图为参考改姿态（提示词禁文字："no text"）。
- **一致性技巧**：同一角色所有图用同一串描述词（外观/配色/装备逐字复用），
  只改姿态与表情短语；edit_ref 时种子固定。
- 表情/吃瘪不再生成新图：用 TheaterStage 的 `dimmed` + `rotate` 动画表达。

## 常见坑

- 角色原型和实体气质不搭（e.g. 把稳健老技术画成刺客）——原型从参数气质反推。
- 描述词逐字漂移 → 跨图不像同一人（V3 违规）。
- 角色太写实/太精致 → 和贴纸风格脱节（全片统一 flat vector sticker）。
- 3 个以上角色抢戏：一支片主角 ≤2，第三方只做道具贴纸不上台。
